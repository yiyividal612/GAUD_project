# Gestión Académica Universitaria Dominicana (GAUD)

## Descripción del proyecto

**Gestión Académica Universitaria Dominicana (GAUD)** es una aplicación web orientada a estudiantes universitarios en RD cuyo propósito es facilitar la gestión y consulta de su progreso académico.

El proyecto busca ofrecer una herramienta que permita a los estudiantes organizar y consultar información relacionada con su carrera universitaria y pensum académico de una manera sencilla, clara y accesible.

GAUD será desarrollado progresivamente durante el trimestre, en 4 fases, incorporando diferentes tecnologías y funcionalidades en cada fase del proyecto.

---

## Objetivo

Desarrollar una aplicación web que permita a los estudiantes gestionar y consultar información relacionada con su carrera y progreso académico.

---

## Tecnologías utilizadas

Durante el desarrollo del proyecto se utilizarán las siguientes tecnologías:

- HTML5
- CSS3
- JavaScript
- Backend y base de datos
- Framework web
- Git y GitHub
- ClikcUp

Las tecnologías y funcionalidades se incorporarán progresivamente de acuerdo con las diferentes fases del proyecto.

---

## Estado actual del proyecto

### Fase 1 — Maquetación del sitio con HTML y CSS

Actualmente el proyecto se encuentra en la **Fase 1**, cuyo objetivo es construir el esqueleto visual de la aplicación web.

En esta fase se está trabajando en:

- Estructura HTML5 semántica.
- Diseño y presentación mediante CSS.
- Navegación entre las diferentes páginas.
- Formulario de registro de usuarios.
- Identidad visual de la aplicación.
- Diseño adaptable a diferentes dispositivos.
- Organización del proyecto mediante Git y GitHub.

En esta etapa no se implementan funcionalidades mediante JavaScript ni conexión con bases de datos (ver a partir de las fases 2 y 3)

---

## Páginas del sitio

La primera versión del sitio contempla las siguientes páginas:

### Inicio

Página principal de la aplicación, donde se presentará información general sobre GAUD y sus principales características.

### Pensum

Página destinada a mostrar la información relacionada con el pensum académico del estudiante.

### Registro

Página destinada al registro de nuevos usuarios.

---

## Registro de usuarios

El formulario de registro contempla información básica del estudiante, incluyendo:

- Nombre completo.
- Correo electrónico.
- Universidad.
- Carrera.
- Contraseña.
- Confirmación de contraseña.
- Aceptación de términos y condiciones.

Para la primera versión del prototipo se incluyen:

**Universidad:**
- Universidad Abierta Para Adultos (UAPA).
- Otra (Próximamente).

**Carreras:**
- Ingeniería de Software.
- Informática Gerencial.
- Ciencia de Datos.

Estas opciones podrán ampliarse en fases posteriores del proyecto.

---

## Identidad visual (ver archivo estilos.css)

GAUD utiliza una identidad visual basada principalmente en:

- Azul oscuro como color principal.
- Azul como color de énfasis.
- Fondos claros.
- Tarjetas y componentes con bordes redondeados.
- Diseño limpio y sencillo.
- Tipografía sans-serif.

La misma identidad visual será utilizada en las diferentes páginas del sitio para mantener una experiencia coherente.
